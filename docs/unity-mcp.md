# Unity MCP: let Claude Code drive the Unity editor

[MCP for Unity](https://github.com/CoplayDev/unity-mcp) (Coplay, MIT, Unity 2021.3 to 6.x) lets
Claude Code read and change the open Unity editor: scenes, GameObjects, components, assets,
scripts, the console and the Test Runner. The repository's `.mcp.json` already points Claude Code
at it, so each developer only installs the Unity side once.

Chosen over Unity's own MCP (`com.unity.ai.assistant`) because that one depends on Unity AI and
its licensing, while this one is free and works offline.

## One-time setup (per machine)

Requirements: Unity 6000.3.27f1, Python 3.10+ and `uv` (`winget install astral-sh.uv`).

1. Open `unity/` in Unity.
2. **Window > Package Manager > + > Add package from git URL** and paste:

   ```
   https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity#v10.0.0
   ```

   This edits `unity/Packages/manifest.json` and `packages-lock.json`. Commit those two files in a
   Unity PR so the whole team gets the package.
3. The setup wizard checks Python and `uv`. Click **Done**.
4. Open **Window > MCP for Unity**, keep the transport on **HTTP** (port 8080) and start the
   server. The status panel shows **Connected** once Claude Code attaches.
5. Open a new Claude Code session in the repository root and approve the `unityMCP` server from
   `.mcp.json` when asked.

The server only runs while the Unity editor is open. Without it, Claude Code simply has no
`unityMCP` tools; nothing else breaks.

## Rules

- The scenes are generated by `MapBuilder` (`unity/Assets/Editor`). Change the builder and
  regenerate instead of editing scenes by hand through the MCP, or the next regeneration loses
  the change.
- Never put API keys in Unity. The MCP only talks to the local editor.
